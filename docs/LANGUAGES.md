# Interface languages

WyzarCapture includes complete explicit translations of its own interface catalog for five languages:

| Selector name | Language | Stored code |
| --- | --- | --- |
| Português (Brasil) | Brazilian Portuguese | `pt-BR` |
| English | English | `en` |
| Español | Spanish | `es` |
| 简体中文 | Simplified Chinese | `zh-Hans` |
| 日本語 | Japanese | `ja` |

## In Setup

Open **Language** in the header and select your language. Welcome, destinations, options, progress, completion, error messages and license controls use that choice. The own freeware terms are included in all five languages. The installer sends the selected language to the installed application as a request applied once during normal startup.

## After installation

Open **Settings › General › Language**. The interface changes immediately and the preference is saved locally. Later application changes survive restart and loading recording profiles; the old Setup choice is not reapplied on every launch.

Translations cover the application's own screens, controls, messages, help and local update history. No language download or online account is needed. Chinese uses Simplified script.

## Text that stays unchanged

Switching language does not rename existing folders, files, projects or user content. Actual device names come from Windows/drivers and remain intact. Language names remain in their own languages so you can find the selector again. API names, file extensions, shortcuts and error codes retain their meaning. Original third-party legal notices retain the rights holders' wording. Windows-provided dialogs and system error descriptions use your Windows language settings.

If a glyph is missing or text is clipped, report the language, screen, Windows build and display scaling. Use a synthetic example without private paths. Native rendering checks on one computer do not certify the font configuration of every Windows installation.
