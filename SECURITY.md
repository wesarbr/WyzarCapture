# Security policy

Use only an official installer attached to the project GitHub Releases. The current prepared update is 0.7.0 Beta; 0.6.1 Beta is the available Release. See beta status for distribution availability. Older or withdrawn installers should not be redistributed. Internal validation records and proprietary sources are not part of this distribution portal.

## Report a vulnerability privately

Do not post exploit details, credentials, private media or sensitive paths in a public Issue. If private vulnerability reporting is available in this repository, use **Security › Advisories › Report a vulnerability**. If it is unavailable, open a minimal Issue requesting a private contact without disclosing the vulnerability. No monitored email address or response deadline is promised here.

Include the application version, Windows build, affected feature, concise reproduction and impact. Share only a minimal synthetic example through a private channel agreed with the owner. Avoid personal recordings and full data folders.

## Suspicious installer or detection

Stop running the affected file, keep Windows/security protection enabled and preserve the detection name and official asset/version information. Do not disable protection, add exclusions or restore a quarantined installer to force installation. A clean local scan for one exact artifact does not certify all systems. This candidate is not signed with a production Authenticode certificate.

Prefer official release links; do not use unofficial mirrors or repackaged executables. The owner has authorized publication of the application and Setup SHA-256 values in docs/CHECKSUMS.md. Private audit records, credentials and signing material are not published.
