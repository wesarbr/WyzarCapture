# Community rules

This applies to the project's Issues, discussions and other community spaces.

- Be respectful and discuss the software and reproducible behavior.
- No harassment, threats, discrimination, impersonation, spam, scams or misleading download links.
- Do not share personal information, private media, credentials, malicious files or instructions intended to compromise another person's system.
- Keep confidential security findings out of public conversations. Use [Security](SECURITY.md).
- Do not demand remote access, security exceptions or execution of untrusted code as a condition for help.

Maintainers may close duplicates and off-topic reports, hide or remove harmful content, lock conversations and report abuse or block abusive accounts using GitHub's controls. Enforcement depends on the behavior and context; support is not a guaranteed response service.

Use GitHub's **Report content** option on harmful material where available. For a non-sensitive moderation request, use the help form and link the relevant conversation without repeating offensive text or private details. If details must remain confidential, request a private contact as described in [Security](SECURITY.md).
