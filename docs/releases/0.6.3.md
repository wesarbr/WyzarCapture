# WyzarCapture 0.6.3 Beta

**Historical release, superseded by 0.7.0 Beta.** Results below describe 0.6.3; see [current status](../BETA_STATUS.md) for the attached installer.

**Your Windows folders. Your drive. A smoother click.**

This update addresses the Windows folder and menu-selection problems reported during 0.6.1 testing. It also includes the storage reserve and basic accessibility improvements prepared in 0.6.2. Application, Setup, help and release messages are embedded in all five supported languages.

## What changed

- **Media by type:** recordings and exports use Windows Videos, screenshots use Pictures, audio uses Music and projects use Documents. Redirected Windows folders are respected.
- **No automatic AppData media fallback:** unavailable destinations stay visible for configuration. Updating the complete former automatic fallback layout backs up preferences and changes future destinations; existing media remains in place. Custom choices remain available.
- **Install on your chosen drive:** select a writable application subfolder on another local drive. Choosing a drive root uses its WyzarCapture subfolder. Media and installation are separate choices; a shared media root is optional.
- **Selection that follows your click:** theme/category changes clear stale focus and refresh hit areas. Clicking another control outside an open selector dismisses the selector and activates that control once.
- **Room to finish:** recording, audio and export check disk space, with a reserve for recovery segments and MP4 assembly. Insufficient or unqueryable space is reported.
- **Basic accessibility:** supported controls expose names, focus, bounds and Invoke/Value/Toggle/RangeValue actions through Windows UI Automation. Complete screen-reader certification remains pending.

## Validation and availability

The exact application and Setup passed the local 33-report pipeline, including 69 unit tests per binary, current-user installation/update/repair/rollback/uninstall, real capture and editor/export, five-language rendering and real UI Automation client actions. Nine themes, ten settings categories and outside-selector navigation were checked in all five languages. A ten-minute 720p/30 recording used disk reserve and media budget guards, then was reopened/decoded and hashed before owned-media cleanup.

The 0.6.3 installer was subsequently attached to the existing Release and has now been superseded by 0.7.0. The [current Release](https://github.com/wesarbr/WyzarCapture/releases/tag/WyzarCapture) contains the 0.7.0 Setup, including these corrections and the later installer changes.

Tests ran on Windows 11 Pro Insider Preview. The affected Windows 10 notebook, stable Windows builds, physical webcam, other GPUs/PCs, physical DPI/multiple monitors and complete accessibility still require real retests. This remains an unsigned current-user beta; it is not a universal stable certification. Windows protections remain enabled and protected folders are not bypassed.
