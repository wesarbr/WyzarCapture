# WyzarCapture 0.6.2 Beta

**Historical prepared candidate, superseded by [0.6.3](0.6.3.md) before distribution.** It predates the new Windows-folder and selection corrections. Availability and results below describe that earlier candidate.

**More room to finish. More ways to reach the controls.**

This prepared update improves recording storage safety, adds basic Windows UI Automation support and extends validation with a bounded ten-minute recording. All new messages and control names are embedded in Brazilian Portuguese, English, Spanish, Simplified Chinese and Japanese.

## What changed

- Video recording reserves space for the recovery segments and assembled MP4. Audio and export also check available space periodically. An unavailable space query is reported instead of silently assumed to be safe.
- Low-space handling stops new work with finalization headroom. If assembly cannot continue, recovery data is preserved. Review partial outputs before sharing.
- Supported controls expose names, screen bounds, focus, navigation and Invoke/Value/Toggle/RangeValue actions through Windows UI Automation. Stable identities preserve search/edit controls during value changes and filtering. Full screen-reader certification remains pending.
- An elevated Setup does not automatically launch the recorder with an elevated token. Current-user/HKCU installation remains the production beta scope.
- The release pipeline now checks a ten-minute capture with duration, disk reserve, media budget, CPU/RAM samples, decoding, hashes and cleanup, alongside the existing capture, audio, editor, installer and language checks.

## Availability and tested scope

The 0.6.2 application and Setup were locally validated but superseded before distribution. The available installer at that time was 0.6.1. The [current Release](https://github.com/wesarbr/WyzarCapture/releases/tag/WyzarCapture) now contains 0.7.0; these historical results do not describe that executable.

The tests ran on Windows 11 Pro Insider Preview. The affected Windows 10 notebook, stable Windows builds, physical webcam, other GPUs/PCs, physical DPI/multiple monitors and complete accessibility still need independent retests. This update remains unsigned beta software. No hours-long stability or universal hardware certification is claimed.
