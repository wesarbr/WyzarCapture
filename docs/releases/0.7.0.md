# WyzarCapture 0.7.0 Beta

**Prepared update:** the exact installer has passed local validation and awaits upload to GitHub. The currently attached download is 0.6.3 Beta. [Release status](../BETA_STATUS.md).

**A cleaner interface, an installer that understands your existing setup, and lighter, sharper capture.**

## Installer

- **Existing installation in another folder:** Setup now shows where WyzarCapture is installed and its version. Choose **Use current folder** to update in place, or install in the new folder to move the program there. Videos, projects and preferences are not moved. Only the old program files are removed, after the new folder is installed and registered.
- **Stale entries no longer block you:** if the previously registered folder was deleted, a new installation proceeds and replaces that entry.
- **Clear layout:** error messages have their own space and no longer cover the options. Progress, completion and the welcome page were redesigned with a vector product illustration.

## Interface

- Segoe UI Variable typography on Windows 11 (Segoe UI on Windows 10), concise functional text instead of slogans, flat controls and a sliding navigation indicator.
- Short transitions for hover, pages, switches, dialogs, menus, tips and notices.
- Each theme has its own subtle animated effect: light sweep (Wyzar Gold and Custom), soft lights (Sapphire), contour lines (Emerald), nebula (Amethyst), waves (Coral), embers (Copper), fine snow (Arctic) and aurora (Aurora). Effects pause while recording or exporting and follow the Windows animation setting; you can turn them off in Appearance.
- The window only redraws when something changes and rebuilds its graphics surface after a display driver change or failure.

## Capture quality

- H.264 with peak-constrained variable bitrate and a keyframe every 2 seconds; the recommended bitrate follows resolution and frame rate and remains adjustable.
- Antialiased scaling when the recording resolution is smaller than the source, so text stays clean.
- Webcam: best native mode up to 720p at 24 FPS or more, read in parallel with the screen; rectangle, rounded or circle shape and an optional mirror.
- **Enhance voice** for the microphone removes low rumble and gently lowers background hiss between phrases (on by default).
- A Windows compatible capture path is used automatically when Windows Graphics Capture is unavailable.

## Validation and availability

The exact application and Setup passed the local 33-report pipeline: 75 unit tests per binary, 60 real current-user installer checks (including moving an installation registered in another folder, refusing a move without confirmation and replacing a stale entry), capture, editing and export, recovery, 405 native renders and 65 checks across five languages, 50 usability renders and 8 Windows UI Automation client actions. A ten-minute 720p/30 recording (600.6 s) was reopened and decoded at the start, middle and end. With the new variable bitrate it used 164 MB of the disk, compared with 443 MB for the same profile and kind of desktop content in 0.6.3. These desktop samples are illustrative, not a controlled benchmark or a guaranteed size reduction. Generated test media was hashed and removed.

Tests ran on Windows 11 Pro Insider Preview. The reported Windows 10 notebook, a physical webcam, other GPUs and PCs, physical DPI/multiple monitors and complete accessibility still require real retests. This remains an unsigned current-user beta. macOS and Linux versions are not available.
