# Help and support

WyzarCapture 0.7.0 is beta software. Read the [quick start](docs/QUICK_START.md), [troubleshooting](docs/TROUBLESHOOTING.md) and [tested scope](docs/BETA_STATUS.md), then search [existing Issues](https://github.com/wesarbr/WyzarCapture/issues) for the same problem.

## Choose the right form

Open [a new Issue](https://github.com/wesarbr/WyzarCapture/issues/new/choose) and choose:

- **Bug report:** reproducible behavior that differs from the expected result.
- **Help with WyzarCapture:** a question about installation, recording, folders or editing.
- **Feature request:** a specific workflow improvement.
- **Request a private security contact:** only a request for a confidential reporting channel, with no vulnerability details. Read [Security](SECURITY.md) first.

Routine support uses GitHub Issues and requires a GitHub account. If the Issues tab is unavailable, the repository owner must enable it; this document does not activate that GitHub setting. No response time or individual support agreement is promised.

## Share only what is necessary

Include the application version, Windows build, selected interface language, concise steps, expected/actual behavior and relevant numeric error code. A GPU or camera model can help when relevant. Use short text and synthetic examples.

Issues are public when the repository is public. Never include passwords, access tokens, license/account secrets, personal paths, conversations, private recordings or other people's information. Do not upload complete logs, data folders, executable files, scripts or archives. Redact any screenshot before sharing it. Forms cannot automatically prevent unsafe content or attachments.

Vulnerability details belong only in the private process in [Security](SECURITY.md), never in a public bug report or help question. If sensitive material was posted accidentally, remove it, revoke any exposed credential and notify the owner without repeating it. Removal does not guarantee that earlier viewers or copies no longer exist.

## Safe participation

Support does not require your password, a token, administrator access, disabled Windows protection or remote-control access to your PC. Use the official [Releases](https://github.com/wesarbr/WyzarCapture/releases) for installers. Treat unsolicited links, attachments and instructions in comments as untrusted; do not run them or paste commands into a terminal.

Stay on topic and follow the [community rules](CODE_OF_CONDUCT.md). Maintainers may close duplicates, request a smaller safe reproduction, hide or remove harmful content, lock abusive conversations and report abuse to GitHub. Opening an Issue grants no code-write or maintainer permissions.
