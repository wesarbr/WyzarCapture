# WyzarCapture 0.6.1 Beta

**Your screen. Your shortcuts. Your folders.**

This update makes screenshots easier to configure, brings your media folders within reach, improves preview controls and corrects two editor behaviors. All new application, help and Setup text is included in the five built-in languages.

## Capture your way

| Feature | What is new |
| --- | --- |
| **PrintScreen** | Choose a monitor, window, region or the recording source. Set a 0, 3, 5 or 10 second delay, include the cursor and optionally copy the image for pasting. PNGs preserve the source dimensions. |
| **Shortcuts** | Click an action and press your preferred key or Ctrl/Alt/Shift/Win combination. Restore F8/F9/F10/PrintScreen, avoid duplicate assignments and see system-conflict messages. |
| **Your folders** | Open or change videos, audio, screenshots, cache, exports and projects from one panel. Prepare a shared media root or choose writable local recovery for unavailable automatic destinations. Existing files stay where they are. |
| **Previews** | Normal startup uses the detected monitor. Compact layouts offer source preview and quick screenshot/folder controls. An available camera can be viewed in an expanded preview with its aspect ratio preserved. |

Camera controls appear when a camera is detected. Previewing a camera and including it in the recording remain separate actions. Camera previews are limited by the device’s supported formats.

## Editor corrections

- Undo/redo after saving correctly marks a changed project as unsaved.
- Export timing uses cumulative frame rounding to avoid adding time to each short cut.
- Local media checks exercised playback, seeking, cuts, effects, history, project reopening and export decoding, including a forty-cut timing regression.

The editor keeps its existing basic effects and independent WAV mix controls. Video cuts do not automatically realign independent WAV tracks, and camera video is not a separate editable track.

## Five languages, one workflow

Brazilian Portuguese, English, Spanish, Simplified Chinese and Japanese are built into Setup and the application. New screenshot, camera, folder and shortcut help follows the selected language. No language-pack download is required.

## Install or update

Use **WyzarCaptureSetup.exe** from the official [Releases page](https://github.com/wesarbr/WyzarCapture/releases). Only this executable is required. Close active recording/export sessions, choose your language, review the application and media destinations, then install for the current Windows user. Existing personal recordings and projects are preserved; changing a destination does not move old files.

Windows x64 is required. The API baseline is Windows 10 version 2004 or later; local validation covers Windows 11 Pro Insider Preview. The affected Windows 10 notebook and a physical webcam still require retesting. This beta has no production Authenticode signature. Consult the tested scope before relying on it for a longer session.
